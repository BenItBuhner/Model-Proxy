# Grid consistency gate — offline audit (ARC-AGI-2 public evaluation, 120 tasks)

Rules a verified program's or direct read's TEST grid must respect when every training pair shares them:
  shape: same-dims-as-input / transposed / constant integer ratio;  palette: output colours ⊆ input colours ∪ colours common to all training outputs;
  cell preservation (same-shape tasks): non-background input cells kept in place / never erased;  degeneracy: single-colour grid when no training output is.
A suspect grid stays votable but never settles a search: at max it forces the independent second attempt (any wave, once), it is excluded from direct-read agreement and backing, and a consistent verified rule outranks it.
